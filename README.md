### Installation & Usage
You have two options to use this code:

**Option 1: As a standalone resource**
1. Place the `Ledge-Grab` folder inside your server's `resources` folder.
2. Add `ensure Ledge-Grab` to your `server.cfg`.

**Option 2: Integrated into an existing script (Recommended)**
Since this script is just a snippet, instead of running it as a standalone resource, you can simply copy all the code from the `client.lua` file and paste it into an existing client-side file within your base (e.g., inside a main script). This helps prevent having too many resources running on your server.
